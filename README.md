# Damián Borda — Portafolio

Portafolio de Damián Borda: ilustración, diseño de producto (UX/UI) y cine.
Estética VHS / terror análogo: cada sección es un canal de TV.

**Sitio:** https://damianborda11.github.io/Portafolio/

## Estructura

```
index.html   → home (trabajos, cine, proceso, servicios, contacto)
works.html   → archivo de trabajos con filtros por disciplina
cine.html    → filmografía con filtros por rol
css/         → estilos
js/data.js   → contenido: proyectos y films como arrays de objetos
js/main.js   → renderizado, filtros, lightbox, canales y formularios
assets/      → imágenes
```

Para agregar un proyecto o un film, edita `js/data.js`.
